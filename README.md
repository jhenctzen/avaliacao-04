# 🌸 Haru Café - Cafeteria Japonesa

Uma **Landing Page** completa, responsiva e elegante desenvolvida exclusivamente com **HTML5** e **CSS3** (sem uso de JavaScript). O projeto foi desenhado sob a temática de uma cafeteria tradicional e moderna japonesa, utilizando uma paleta de cores inspirada no desabrochar das cerejeiras (*Sakura*) e no minimalismo oriental.

Este projeto serve como modelo de portfólio para a exibição de produtos, contendo seções de cardápio estruturadas e um sistema de carrinho funcional em janela modal implementado puramente via CSS.

---

## 🚀 Funcionalidades

- **Design Responsivo (Mobile-First):** Layout otimizado para dispositivos móveis, tablets e desktops utilizando *Media Queries*.
- **Visual Temático Customizado:** Cores suaves, fontes legíveis e disposição em cartões que valorizam a fotografia dos produtos.
- **Modal de Carrinho Sem JavaScript:** Implementação do padrão *Checkbox Hack* no CSS para abrir e fechar a janela do carrinho de compras de forma 100% nativa.
- **Favicon Integrado:** Ícone personalizado de *Sakura* na aba do navegador.
- **Seções Separadas:** Divisão inteligente entre Bebidas/Chás Especiais e Doces/Sobremesas Tradicionais.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página (tags `header`, `main`, `section`, `footer`).
- **CSS3:** Estilização completa, uso de *CSS Grid*, *Flexbox*, animações `@keyframes` e transições suaves.
- **Unsplash API (Imagens):** Links diretos para fotografias de alta qualidade.
